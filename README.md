# book-collecton

個人の蔵書（本のコレクション）を管理するWebアプリです。このリポジトリには、開発の経緯により**2つのバージョン**が入っています。用途に応じて使い分けてください。

両方とも、カメラ/バーコードリーダーでのISBN読み取り、openBD・Google Books・Open Libraryを使った書誌情報の自動取得、書名・著者でのキーワード候補検索、一覧のリスト表示、メモ欄、JSON/CSVのエクスポート・インポートなど、**基本機能は同じ**です。違いはデータの保存・同期方法だけです。

## 2つのバージョンの違い

| | [`サーバー利用版/`](./サーバー利用版/) | [`完全ローカル版/`](./完全ローカル版/book-collecton-main/) |
|---|---|---|
| **位置づけ** | 現在開発中の最新版 | Firebase導入前の状態のバックアップ（旧版） |
| **データの保存先** | Firebase Firestore（クラウド） | ブラウザのIndexedDB（端末内のみ） |
| **複数端末での同期** | ○ できる（Googleアカウントでサインイン） | ✕ できない（端末ごとに別々のデータ） |
| **インターネット接続** | 必須（オフラインでは登録・閲覧不可） | 不要（完全オフラインで動作） |
| **サインイン・アカウント登録** | 必要（Googleアカウント） | 不要 |
| **事前準備** | Firebaseプロジェクトの作成・設定が必要 | 不要。ダウンロードしてすぐ使える |

## どちらを使えばいいか

- **スマートフォン・PCなど複数端末で同じ蔵書データを見たい・登録したい** → `サーバー利用版/` を使ってください。Firebaseの設定が必要です（詳しくは[サーバー利用版/README.md](./サーバー利用版/README.md)の「Firebaseのセットアップ」を参照）。
- **1台の端末だけで使う・クラウドサービスへの登録をしたくない・オフラインで使いたい** → `完全ローカル版/book-collecton-main/` を使ってください。簡易HTTPサーバーで配信するだけで、Firebase等の追加設定なしに動作します（`file://` では動作しないため、サーバー利用版と同様に `python3 -m http.server` 等での配信が必要です）。

それぞれの詳しい機能・使い方・セットアップ方法は、各フォルダ内のREADMEを参照してください。
