# 蔵書管理アプリ（book-collecton）

個人の蔵書（本のコレクション）を管理する、ブラウザだけで動くWebアプリです。
バーコード（ISBN）をカメラでスキャンすると書誌情報（書名・著者・出版社・出版日・表紙画像）を自動取得し、
一覧・検索・編集・削除ができます。

Googleアカウントでサインインすると、Firebase（Firestore）経由でスマートフォン・PCなど複数端末の蔵書データを
リアルタイムに同期します。**利用にはFirebaseプロジェクトの設定が必須**です（後述の「Firebaseのセットアップ」参照）。
未設定の状態でアプリを開くと、設定を促す案内が表示されるだけで、登録・閲覧などの機能は使えません。

## 主な機能

- ☁️ **複数端末での同期**：Googleアカウントでサインインすると、Firebase Firestoreを通じてスマートフォン・PCなど複数端末の蔵書データがリアルタイムに同期される（自分のアカウントのデータは他人からは見えない）
- 📷 **カメラでの読み取り**：端末のカメラでISBNバーコード（EAN-13）を読み取り、書誌情報を自動取得
- 🔌 **バーコードリーダーでの読み取り**：USB/Bluetooth接続のキーボードエミュレーション型バーコードリーダーに対応。「バーコードリーダーで読み取る」から明示的に開始できるほか、入力欄を編集中でなければ画面のどこからでもそのまま読み取り可能
- 🔎 **ISBN検索**：[openBD](https://openbd.jp/)（日本の書籍）→ [Google Books API](https://developers.google.com/books) → [Open Library](https://openlibrary.org/) の順にフォールバック。洋書やopenBDに登録のない本のヒット率を上げるため2種類の海外APIを併用
- 🔎 **書名・著者キーワード検索**：ISBNで見つからない場合に、書名・著者などのキーワードでGoogle Books / Open Libraryから候補を検索し、一覧から選ぶだけで自動入力できる（洋書やISBNが不明な本の登録の手間を軽減）
- ✏️ **手入力フォーム**：バーコードがない本（自費出版・古書・海外の本など）も登録可能。スキャン結果の修正にも使用
- 📝 **メモ欄**：保管場所・貸出状況・感想など、本ごとに自由記述のメモを残せる（一覧にも先頭部分がプレビュー表示される）
- 📚 **一覧・検索・並び替え**：表紙画像・書名・著者・メモのプレビューを横並びで表示するリスト形式、書名・著者でのキーワード検索、登録日・書名・著者順の並び替え
- 🔁 **重複登録チェック**：既に登録済みのISBNをスキャン・入力すると警告
- ⬇️⬆️ **バックアップ（JSON / CSV）のエクスポート・インポート**：クラウド障害時などに備えたデータ消失対策

## 使い方

0. 初回はヘッダー右上の「🔐 サインイン」（または画面中央の案内）からGoogleアカウントでサインインしてください。以降はサインインしている端末同士で蔵書データが自動的に同期されます。
1. 「📷 カメラで読み取る」でカメラを起動し、本の裏表紙のISBNバーコードを映すと自動で書誌情報を取得します。
   USB/Bluetoothのバーコードリーダーをお持ちの場合は「🔌 バーコードリーダーで読み取る」から開始してください。カメラを使わず、リーダーでの読み取りを待つ画面が表示されます。なお、入力欄を編集していない状態であれば、このボタンを押さなくても画面のどこからでもそのままリーダーで読み取らせて登録できます。
2. 内容を確認して「保存」を押すと蔵書に登録されます。
3. バーコードがない本は「✏️ 手入力で登録」から書名などを直接入力してください。ISBNで書誌情報が見つからない場合（洋書など）は、登録フォーム内の「🔎 書名・著者で候補を探す」から書名・著者のキーワードで検索し、候補一覧から選ぶと自動入力できます。
4. ISBNだけわかっている場合は「🔎 ISBNで検索」でバーコードなしでも書誌情報を取得できます。
5. 画面上部の検索ボックスで書名・著者を絞り込み、並び替えメニューで表示順を変更できます。
6. 一覧の本をタップすると詳細・編集・削除ができます。
7. 「⬇️ エクスポート」でJSON/CSV形式のバックアップファイルをダウンロードし、「⬆️ インポート」でクラウドへ一括登録できます。
8. Firebase導入前にその端末のIndexedDBに残っていたデータがある場合、サインイン後に「クラウドにアップロードしますか？」という案内が表示されるので、必要に応じて移行できます。

## 記録するデータ項目

ISBN／書名／著者／出版社／出版日／メモ／表紙画像／登録日（自動記録）

## Firebaseのセットアップ（利用開始に必須）

1. [Firebaseコンソール](https://console.firebase.google.com)にGoogleアカウントでログインし、新規プロジェクトを作成します（無料）。
2. 左メニュー「Firestore Database」→「データベースを作成」。リージョンは `asia-northeast1`（東京）がおすすめです。
3. 左メニュー「Authentication」→「Sign-in method」タブで「Google」を有効化します。
4. 同じく「Authentication」→「Settings」タブの「承認済みドメイン」に、このアプリを配信するドメイン（例: GitHub Pagesの `xxxx.github.io`）を追加します。`localhost` は最初から登録されています。
5. 「プロジェクトの設定」（⚙️アイコン）→「全般」タブの「マイアプリ」からウェブアプリを追加し、表示された `firebaseConfig` の値を `js/cloud.js` 冒頭の `FIREBASE_CONFIG` に貼り付けます。
6. Firestoreの「ルール」タブに以下を貼り付けて公開し、本人のデータしか読み書きできないようにします。

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId}/books/{bookId} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```

7. `js/cloud.js` を保存してデプロイ（またはローカルで再読み込み）すれば、サインインして使えるようになります。

Firestore・Authenticationとも無料枠（Sparkプラン）の範囲で、個人の蔵書管理用途であれば十分足りる見込みです。アップロードした表紙画像（ファイル選択）はFirestoreには保存されず、その端末のIndexedDBにのみキャッシュされます（同期されるのは書誌情報APIから取得したURL形式の表紙画像のみ）。

## 技術構成

- 素のHTML / CSS / JavaScript（ビルド不要、フレームワーク不使用）
- カメラでのバーコード読み取り：[html5-qrcode](https://github.com/mebjas/html5-qrcode)（CDN経由で読み込み、ISBN関連フォーマット=EAN-13/EAN-8/UPC-A/UPC-Eのみに限定）
- ハードウェアバーコードリーダー対応：キーボードエミュレーション型の入力を打鍵間隔で判定する独自ロジック（`js/hardwareScanner.js`）
- 書誌情報API：openBD → Google Books API → Open Library（ISBN検索のフォールバック）／書名・著者キーワード検索はGoogle Books + Open Libraryを併用
- データ保存：Firebase Firestore（Googleアカウント単位、複数端末でリアルタイム同期）。アップロード画像のみブラウザの IndexedDB に端末ローカルでキャッシュ
- 認証：Firebase Authentication（Googleサインイン、リダイレクト方式）

```
index.html          エントリーポイント
css/style.css        スタイル（ライト/ダークモード対応・レスポンシブ）
js/cloud.js           Firebase Authentication / Firestore 連携（サインイン・データ同期）
js/db.js             IndexedDB（アップロード画像のローカルキャッシュ・移行元データの読み出し）
js/api.js            ISBN検索・書名/著者キーワード検索（openBD / Google Books / Open Library）
js/scanner.js         カメラバーコードスキャン（html5-qrcode ラッパー）
js/hardwareScanner.js USB/Bluetoothバーコードリーダー（キーボードエミュレーション型）の検出
js/csv.js             CSV/JSON エクスポート・インポート
js/app.js             画面制御・イベント処理
```

## ローカルでの動作確認

ES Modulesを使用しているため、`file://` では動作しません。簡易HTTPサーバーで配信してください。

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。カメラ機能はHTTPS（またはlocalhost）でのみ動作します。

## 注意事項・制限

- **利用にはFirebaseの設定とインターネット接続が必須です。** オフライン時は登録・閲覧ともにできません（この点は当初の「サーバー同期なし」という方針から転換しています）。
- アップロードした表紙画像（ファイル選択）はその端末のIndexedDBにのみキャッシュされ、クラウドには同期されません。別端末では表示されない点にご注意ください（URL形式の表紙画像は同期されます）。
- 万一に備え、定期的に「⬇️ エクスポート」でバックアップを取得することを推奨します。
- Firebaseの無料枠（Sparkプラン）はFirestoreの読み書き回数などに上限がありますが、個人の蔵書管理用途であれば通常は問題にならない見込みです。
