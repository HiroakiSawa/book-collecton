# 蔵書管理アプリ（book-collecton）

個人の蔵書（本のコレクション）を管理する、ブラウザだけで動くWebアプリです。
バーコード（ISBN）をカメラでスキャンすると書誌情報（書名・著者・出版社・出版日・表紙画像）を自動取得し、
一覧・検索・編集・削除ができます。データは端末内（ブラウザのIndexedDB）にのみ保存され、
サーバーへの送信・同期は一切行いません。

## 主な機能

- 📷 **カメラでの読み取り**：端末のカメラでISBNバーコード（EAN-13）を読み取り、書誌情報を自動取得
- 🔌 **バーコードリーダーでの読み取り**：USB/Bluetooth接続のキーボードエミュレーション型バーコードリーダーに対応。「バーコードリーダーで読み取る」から明示的に開始できるほか、入力欄を編集中でなければ画面のどこからでもそのまま読み取り可能
- 🔎 **ISBN検索**：[openBD](https://openbd.jp/)（日本の書籍）→ [Google Books API](https://developers.google.com/books) → [Open Library](https://openlibrary.org/) の順にフォールバック。洋書やopenBDに登録のない本のヒット率を上げるため2種類の海外APIを併用
- 🔎 **書名・著者キーワード検索**：ISBNで見つからない場合に、書名・著者などのキーワードでGoogle Books / Open Libraryから候補を検索し、一覧から選ぶだけで自動入力できる（洋書やISBNが不明な本の登録の手間を軽減）
- ✏️ **手入力フォーム**：バーコードがない本（自費出版・古書・海外の本など）も登録可能。スキャン結果の修正にも使用
- 📚 **一覧・検索・並び替え**：表紙画像を中心としたグリッド表示、書名・著者でのキーワード検索、登録日・書名・著者順の並び替え
- 🔁 **重複登録チェック**：既に登録済みのISBNをスキャン・入力すると警告
- ⬇️⬆️ **バックアップ（JSON / CSV）のエクスポート・インポート**：端末内保存のみのためのデータ消失対策
- オフライン・非対応環境への配慮：カメラや保存機能が使えない端末でも手入力フォーム自体は動作します

## 使い方

1. 「📷 カメラで読み取る」でカメラを起動し、本の裏表紙のISBNバーコードを映すと自動で書誌情報を取得します。
   USB/Bluetoothのバーコードリーダーをお持ちの場合は「🔌 バーコードリーダーで読み取る」から開始してください。カメラを使わず、リーダーでの読み取りを待つ画面が表示されます。なお、入力欄を編集していない状態であれば、このボタンを押さなくても画面のどこからでもそのままリーダーで読み取らせて登録できます。
2. 内容を確認して「保存」を押すと蔵書に登録されます。
3. バーコードがない本は「✏️ 手入力で登録」から書名などを直接入力してください。ISBNで書誌情報が見つからない場合（洋書など）は、登録フォーム内の「🔎 書名・著者で候補を探す」から書名・著者のキーワードで検索し、候補一覧から選ぶと自動入力できます。
4. ISBNだけわかっている場合は「🔎 ISBNで検索」でバーコードなしでも書誌情報を取得できます。
5. 画面上部の検索ボックスで書名・著者を絞り込み、並び替えメニューで表示順を変更できます。
6. 一覧の本をタップすると詳細・編集・削除ができます。
7. 「⬇️ エクスポート」でJSON/CSV形式のバックアップファイルをダウンロードし、「⬆️ インポート」で復元・別端末への移行ができます。

## 記録するデータ項目

ISBN／書名／著者／出版社／出版日／表紙画像／登録日（自動記録）

## 技術構成

- 素のHTML / CSS / JavaScript（ビルド不要、フレームワーク不使用）
- カメラでのバーコード読み取り：[html5-qrcode](https://github.com/mebjas/html5-qrcode)（CDN経由で読み込み、ISBN関連フォーマット=EAN-13/EAN-8/UPC-A/UPC-Eのみに限定）
- ハードウェアバーコードリーダー対応：キーボードエミュレーション型の入力を打鍵間隔で判定する独自ロジック（`js/hardwareScanner.js`）
- 書誌情報API：openBD → Google Books API → Open Library（ISBN検索のフォールバック）／書名・著者キーワード検索はGoogle Books + Open Libraryを併用
- データ保存：ブラウザの IndexedDB（端末内のみ、サーバー同期なし）

```
index.html          エントリーポイント
css/style.css        スタイル（ライト/ダークモード対応・レスポンシブ）
js/db.js             IndexedDB 永続化
js/api.js            ISBN検索・書名/著者キーワード検索（openBD / Google Books / Open Library）
js/scanner.js         カメラバーコードスキャン（html5-qrcode ラッパー）
js/hardwareScanner.js USB/Bluetoothバーコードリーダー（キーボードエミュレーション型）の検出
js/csv.js             CSV/JSON エクスポート・インポート
js/app.js             画面制御・イベント処理
```

## ローカルでの動作確認

ES Modulesを使用しているため、`file://` では動作しません。簡易HTTPサーバーで配信してください。

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。カメラ機能はHTTPS（またはlocalhost）でのみ動作します。

## 注意事項・制限

- データは各端末のブラウザ内にのみ保存されます。ブラウザのデータ消去やアプリの再インストール等で失われる可能性があるため、定期的なエクスポート（バックアップ）を推奨します。
- 書誌情報API・カメラライブラリの読み込みにはインターネット接続が必要です（オフライン時は手入力のみ利用できます）。
- URLで指定した表紙画像は、後でオフラインになると表示できない場合があります（アップロードした画像はブラウザ内に保存されるため引き続き表示されます）。
